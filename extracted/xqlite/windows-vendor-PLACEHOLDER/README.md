# Pendiente: vendor de XQLite Windows

Esta carpeta debe recibir el contenido de:

```text
D:\XQLite-Windows\XQLite\vendor\
```

Archivos esperados:

- `hashcod_form_builder.py`
- `opencriptg_ui.py`
- `opencriptg_vault.py`
- `opencriptg_security.py`
- `opencriptg_generators.py`
- `opencriptg_catalog.json`
- `data\` (si existe)

Ejecuta `../extract-xqlite-windows.ps1` en tu PC y sube `D:\XQLite-Windows-SOURCE.zip`.
